# collaborativearchitecture.com

**What this is:** the website of Collaborative Architecture, Mumbai and Riyadh.

It is one source file, turned into a static site that works on any host. There is no CMS and no database; the only server-side code is two small PHP form handlers.

**Pick your guide:**

- **Host or developer putting the site online:** read [`docs/HOST-GUIDE.md`](docs/HOST-GUIDE.md).
- **Studio:** to change the site, ask Claude in the WEBSITE project. It edits this repository, shows a preview, and pushes the change, which goes live automatically once deployment is set up (HOST-GUIDE, section 11).

## Layout

| Path | What it is |
|---|---|
| `src/ca-website.html` | The whole site in one file: text and data (projects, awards, press, Lab), layout, behavior and search-engine data. |
| `public/` | Copied to the site as it is: `img/` (WebP pictures, press covers, share cards), `vid/` (films), `press/` (book pages and magazine features, PDF), `fonts/`, `api/` (form handlers), icons, `site-config.js`. |
| `server/redirects.txt` | Old WordPress addresses → new ones (301), and gone ones (410). |
| `server/nginx.conf` | nginx settings. Generated by the build. |
| `tools/build.js` | The build. Writes `dist/`: every page as static HTML, the search files, `.htaccess`, `_redirects` and `_headers`, then checks the result. |
| `tools/media.py` | Replaces a picture from a studio original: WebP, small copy, share card and placeholder color. |
| `.github/workflows/deploy.yml` | On every push to `main`: build, check, publish to the `live-site` branch, and upload to the server (FTP or SSH) when configured. |
| `docs/HOST-GUIDE.md` | Upload, forms, DNS, HTTPS, launch checks, rollback. |

## Build

```bash
npm install && npx playwright install chromium
npm run build            # → dist/  (collaborativearchitecture.com)
npm run build:staging    # → dist-staging/  (noindex everywhere, for a test address)
```

The build fails if any of these is true:

- a page still carries review wording (draft, ⚑, "to be supplied");
- a page has an inline script (the security policy forbids them);
- a link points to a missing page;
- a picture or film is missing.

## Two modes, one source

`src/ca-website.html` is also the studio's review copy on claude.ai.

- **Review copy:** shows the draft badge, the SEO check, the review notes, the ⚑ flags and the admin.
- **Published site:** `tools/build.js` marks every page `data-live="1"`, which hides all of the above. The forms post to `/api/`, analytics load only after consent, and the fonts come from the site itself.

## Pictures

To put a new picture on the site:

```bash
python3 tools/media.py "path/to/original.jpg" img/bgrt/p01 --share reflected-topography
npm run build
```

- Names follow the site: `p01…` photographs, `d01…` drawings, `s01…` sketches, `c01-t…` press covers, in `img/<project>/`.
- Which pictures to replace, and the size to supply, is listed in the image and media audit, `image-media-audit-2.5.csv` in the WEBSITE project.
