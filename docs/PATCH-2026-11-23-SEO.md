# Live patch 2026-11-23-seo1: search, AI crawlers, UAE and Saudi city pages

On top of 2026-11-21-patch1. Built from the live text copy with `make_patch_seo.py`; the data and code changes are mirrored in
`src/ca-website.html` in this commit. Three changes live only in the publishing pipeline (not in this repository) and must be
carried into it before the next full build:

1. **Title and author in the head.** The pipeline closes `</head>` before the template's `<title>`, the default
   `<meta name="description">` (the Home text) and `<meta name="author">`, so every page carried its title in `<body>` and a
   second, generic description. The patch moves the title and author into the head (before the page's own description) and
   drops the generic description when the page has its own.
2. **`<!--email_off-->` … `<!--/email_off-->`** around the body content, so Cloudflare's Email Address Obfuscation leaves the
   enquiry@ links alone (Semrush Site Audit, 21 Nov: 22 broken links to /cdn-cgi/l/email-protection).
3. **Copy-protection guard (first inline script).** Its placeholder page is written with `\x3c` for `<` and `no\x69ndex`,
   so the raw source of an indexable page no longer contains a `<title>`, `<h1>` or `noindex` that simple crawlers could
   take for the page's own. Behavior unchanged; CSP hash `EXuFwZU8…` becomes `so78EsL13WkSv15ejZupKLYhNIGDM9+A9L5nirao6W4=`
   (.htaccess, _headers, nginx.conf).

Also in the patch: sitemap.xml and robots.txt are edited by hand, not regenerated (a regenerated robots.txt drops the
site-copying block of 13 Nov; the feed generator still names the first Sandy Hook picture p01 instead of p01r2).

Data and code (mirrored here): eight Gulf city pages (`gulf:` places, 120-word introductions, "Across the Gulf"),
country titles naming the main cities, search titles for BGRT, Mezban, The Legend, Stacked Tectonics and BGRT Mumbai,
Kerala/Calicut, interior designers in Mumbai and Dubai, the institutional services line, 14 cities and 4 subjects in the
structured data, and redirects for /projects/indian-national-peace-museum and /projects/stacked-tectonics.
