## Tests

- Apache 2.4 and nginx 1.24, the 23 Nov server files against the gsc1 files, same document tree (tools/patches/gsc1/srvtest.py):
  the 123 Search Console addresses and 543 others (every page, asset, feed, Markdown copy and every old-address rule, with and
  without the trailing slash, plus query and edge cases). Only the intended answers change: 15 of the 123 and 9 of the 543
  (variants of the same rules). Apache and nginx give identical answers. CSP, cache and Link headers unchanged on every
  address; the copy guard, the www and http redirects and the Markdown negotiation are unchanged.
- The 23 Nov files reproduce what the live server answers today for the 123 addresses (checked in a browser on the live site).
- Home page under load (3,000 requests): 9.0 to 10.3 ms per request before, 9.8 to 10.0 ms after, the same within noise.

## Not changed, and why

- The five new pages are healthy (200, index, self canonical, in the sitemap, linked from the country pages after rendering);
  Google crawled them on 24 Nov and has not decided yet. Request indexing in URL Inspection.
- /news/press/ keeps /news/ as canonical: its static HTML is the News page, and the old press addresses already redirect to it.
- The press PDF (Hinge 199, 2012) stays open to indexing; Google decides per file.
